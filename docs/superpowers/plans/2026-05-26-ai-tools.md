# Phase 5b: AI 工具扩展实现计划

> **For agentic workers:** Use superpowers:subagent-driven-development to implement.

**Goal:** 新增 5 个写工具 + 3 个读工具，让 AI 能全面操控项目管理系统。

**Architecture:** 新建 `WriteTools.java`（5 个写工具）和 `ReadTools.java`（3 个读工具），每个 @Tool 方法包裹 try/catch 计时日志（与 TaskTools 模式一致）。

**Tech Stack:** Spring Boot 3.3, MyBatis-Plus 3.5.9, Spring AI 1.0.0-M6

---

### 文件创建

#### 1. `backend/src/main/java/com/breeze/ai/WriteTools.java`

5 个写工具，每个记录执行日志：

**工具 1: update_task** — 更新任务字段
```java
@Tool(name = "update_task", description = "更新任务字段。需提供任务ID。可选：标题、描述、状态、优先级、类型、截止日期、预估工时")
public String updateTask(
    @ToolParam(description = "任务ID") Long taskId,
    @ToolParam(description = "新标题（可选）") String title,
    @ToolParam(description = "新描述（可选）") String description,
    @ToolParam(description = "新状态: todo/in_progress/review/done（可选）") String status,
    @ToolParam(description = "新优先级: low/medium/high/urgent（可选）") String priority,
    @ToolParam(description = "截止日期 yyyy-MM-dd（可选）") String dueDate,
    @ToolParam(description = "预估工时（小时，可选）") Integer estimatedHours)
```
- 调用 `taskMapper.selectById(taskId)` 获取任务
- 仅更新非 null 参数
- 调用 `taskMapper.updateById(task)`
- 返回 `"任务 {key} 已更新"`

**工具 2: assign_task** — 分配任务
```java
@Tool(name = "assign_task", description = "将任务分配给指定成员")
public String assignTask(
    @ToolParam(description = "任务ID") Long taskId,
    @ToolParam(description = "成员用户名或显示名") String assigneeName)
```
- 查找用户（与 create_task 相同的模式）
- 更新 task.assigneeId
- 返回 `"任务 {key} 已分配给 {name}"`

**工具 3: add_comment** — 添加评论
```java
@Tool(name = "add_comment", description = "给任务添加评论")
public String addComment(
    @ToolParam(description = "任务ID") Long taskId,
    @ToolParam(description = "评论内容（支持 Markdown）") String content)
```
- 调用 `commentService.create(taskId, request, 0L)`（userId=0 表示 AI）
- 返回 `"评论已添加到任务 {key}"`

**工具 4: create_subtasks** — 批量创建子任务
```java
@Tool(name = "create_subtasks", description = "为父任务批量创建子任务")
public String createSubtasks(
    @ToolParam(description = "父任务ID") Long parentTaskId,
    @ToolParam(description = "子任务标题列表，JSON 数组格式，如 [\"子任务1\", \"子任务2\"]") String titlesJson)
```
- 解析 JSON 数组 → `List<String>`
- 获取父任务（获取 projectId）
- 循环调用 `taskService.create(projectId, subtask, 0L)`
- 设置 `subtask.parentId = parentTaskId`
- 返回 `"已创建 N 个子任务"`

**工具 5: add_to_sprint** — 加入 Sprint
```java
@Tool(name = "add_to_sprint", description = "将任务添加到 Sprint")
public String addToSprint(
    @ToolParam(description = "任务ID") Long taskId,
    @ToolParam(description = "Sprint ID") Long sprintId)
```
- 调用 `sprintService.addTask(sprintId, taskId)`
- 返回 `"任务 {key} 已添加到 Sprint {name}"`

**依赖注入:**
```java
private final TaskMapper taskMapper;
private final TaskService taskService;
private final UserMapper userMapper;
private final SprintService sprintService;
private final SprintMapper sprintMapper;
private final CommentService commentService;
private final AiToolExecutionMapper toolExecutionMapper;
private final ObjectMapper objectMapper;
```

每个方法都用与 TaskTools 相同的 try/catch + logToolExecution 模式。

#### 2. `backend/src/main/java/com/breeze/ai/ReadTools.java`

3 个读工具：

**工具 6: get_task_detail** — 获取任务详情
```java
@Tool(name = "get_task_detail", description = "获取任务完整信息，包括标题、描述、状态、指派人、评论列表")
public String getTaskDetail(
    @ToolParam(description = "任务ID") Long taskId)
```
- 查询 Task、指派人信息
- 查询该任务的评论（最近 10 条）
- 返回格式化的文本摘要

**工具 7: get_sprint_status** — Sprint 进度
```java
@Tool(name = "get_sprint_status", description = "获取 Sprint 进度：已完成/总量、完成率")
public String getSprintStatus(
    @ToolParam(description = "Sprint ID") Long sprintId)
```
- 调用 `sprintService.getById(sprintId)` 获 DTO（含 taskCount/completedTaskCount）
- 调用 `sprintService.burndown(sprintId)` 获取燃尽趋势简述
- 返回 `"Sprint {name}: {completed}/{total} 完成 ({percent}%)，状态: {status}"`

**工具 8: get_user_workload** — 成员负载
```java
@Tool(name = "get_user_workload", description = "获取项目成员的当前任务负载")
public String getUserWorkload(
    @ToolParam(description = "项目ID") Long projectId)
```
- 查询项目所有未完成任务
- 按指派人分组
- 返回 `"成员负载: 张三: 5个任务(进行中3, 待办2), 李四: 3个任务..."`

**依赖注入:**
```java
private final TaskMapper taskMapper;
private final UserMapper userMapper;
private final SprintService sprintService;
private final CommentMapper commentMapper;
private final AiToolExecutionMapper toolExecutionMapper;
private final ObjectMapper objectMapper;
```
